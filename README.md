Minha Biblioteca
Sobre o projeto
O Minha Biblioteca é um projeto desenvolvido com React que utiliza uma API pública para buscar e mostrar informações sobre livros.

A aplicação exibe a capa, o título e o autor de cada livro.
Tecnologias utilizadas
- React
- Vite
- JavaScript
- Axios
- CSS
- Open Library API
API utilizada
Foi utilizada a API Open Library para buscar os livros.

Endereço: https://openlibrary.org

Organização do projeto
- App.jsx: página principal, responsável por buscar e mostrar os livros.
- Livro.jsx: componente responsável por mostrar cada livro.
- api.js: configura o Axios e o endereço da API.
- App.css: responsável pela aparência da aplicação.
- main.jsx: inicia a aplicação React.



Conclusão
Com este projeto, foi possível aprender a consumir uma API utilizando Axios, trabalhar com os hooks useState e useEffect e exibir informações na tela utilizando React.
O projeto também ajudou a entender melhor a organização de arquivos e a criação de componentes.
Atividade individual – Listagem de Dados com React, Vite e Axios.
